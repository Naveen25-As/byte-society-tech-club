# Tech Club Website

A responsive college Tech Club website built with HTML5, CSS3, and Bootstrap 5.

## Features

- **Responsive Navbar**: Fixed navigation with smooth scrolling and mobile hamburger menu
- **Hero Section**: Eye-catching hero with gradient background and CTA button
- **About Section**: Information about the club's mission and offerings
- **Events Section**: Upcoming event cards with registration buttons
- **Projects Section**: Showcase of member projects with technology tags
- **Team Section**: Team member cards with avatars and roles
- **Contact Form**: Functional contact form with validation
- **Footer**: Quick links and contact information

## Technologies Used

- HTML5 (Semantic markup)
- CSS3 (Custom styles and animations)
- Bootstrap 5 (Responsive framework)
- Font Awesome (Icons)
- JavaScript (Interactivity)

## File Structure

```
tech-club-website/
├── index.html          # Main HTML file
├── style.css           # Custom CSS styles
├── script.js           # JavaScript functionality
└── README.md           # Project documentation
```

## How to Use

1. Open `index.html` in a web browser
2. Or use a local server:
   ```bash
   cd tech-club-website
   python -m http.server 8000
   ```
   Then navigate to `http://localhost:8000`

## Responsive Design

The website is fully responsive and optimized for:
- Mobile devices (< 576px)
- Tablets (576px - 768px)
- Desktop (768px and above)

## Features Implemented

- Smooth scrolling navigation
- Mobile-responsive navbar with collapse functionality
- Hover effects on cards
- Form validation
- Active navigation link highlighting
- Scroll-based navbar styling
- Fade-in animations
- Custom scrollbar styling
- Dynamic year in footer

## Customization

To customize the website:
1. Edit `index.html` to change content
2. Modify `style.css` to adjust styling
3. Update `script.js` to change JavaScript functionality
4. Replace placeholder content with actual club information
